# 90日ダイエット実践アプリ

URLで公開して使う前提のWebアプリです。Vercel / Netlify / GitHub Pages にアップロードできます。

## 機能
- 目標体重・開始日・期限設定
- 基礎代謝・総消費カロリー・目標摂取カロリー計算
- 減量用マイナスkcal設定
- PFCバランス設定とPFC目標g自動計算
- 毎日の体重・カロリー・PFC・歩数・運動・メモ記録
- 達成率・残りkg・期限までの日数
- 体重グラフ
- CSV出力
- スマホ対応

## 公開方法（簡単）
### Netlify
1. https://app.netlify.com/drop を開く
2. このフォルダをドラッグ&ドロップ
3. 発行されたURLを販売ページに載せる

### Vercel
1. GitHubにこのフォルダをアップロード
2. VercelでNew Project
3. そのリポジトリを選んでDeploy

## 注意
データは利用者のブラウザ内 `localStorage` に保存されます。会員登録・クラウド同期はありません。
